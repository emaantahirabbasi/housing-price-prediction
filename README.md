# 🏠 Housing Price Prediction

## Overview
Linear Regression model predicting housing prices on 545 property records. Achieved R² = 0.65 through feature engineering and a full preprocessing pipeline.

## 📊 Key Results
- **R² Score:** 0.65
- **One-hot encoding** applied to 7 categorical variables
- Built a full **scikit-learn preprocessing pipeline**

## 🛠️ Tech Stack
Python | scikit-learn | Pandas | NumPy | Matplotlib | Seaborn

## 📁 Dataset
Housing Prices Dataset — 545 records with 13 features

## 🚀 How to Run
1. Clone: `git clone https://github.com/emaantahirabbasi/housing-price-prediction`
2. Install: `pip install pandas scikit-learn matplotlib seaborn`
3. Open: `jupyter notebook housing_price_prediction.ipynb`
